# Validated Numerics for Majumdar–Papapetrou Lapse Bifurcations

`validated_mp` — independent, outward-rounded validated-numerics reproduction of the
Majumdar–Papapetrou (MP) three-center lapse critical-point results
(symmetric family `(M1,M2,M3)=(1,1,λ)` and asymmetric family
`(1+ε,1-ε,λ)`), built independently of the original Python/SymPy/mpmath.iv
computation, using Julia's `IntervalArithmetic.jl` (outward-rounded interval
arithmetic) and `Arblib.jl` (arbitrary-precision ball arithmetic, wrapping
Arb/FLINT).

See `output/proof_summary.txt` for the live, authoritative PASS/FAIL table
(regenerated by `proof/proof_all.jl`); the table below is a snapshot.

## Paper

**[Lapse-Gradient Topology of Static Multi-Black-Hole Spacetimes (PDF)](lapse_gradient_topology_manuscript_en.pdf)**
— the manuscript this repository certifies (Markdown source:
[`lapse_gradient_topology_manuscript_en.md`](lapse_gradient_topology_manuscript_en.md)).

**Motivation.** The starting idea was to treat the lapse function
`N = dτ/dt` of a static spacetime — the local gravitational-redshift factor —
as a scalar field in its own right, and to ask whether the *global shape* of
a gravitational field could be classified the way a Morse function classifies
a manifold: by its finite critical points, their indices, and the gradient
flow connecting them. Majumdar-Papapetrou multi-black-hole spacetimes are an
ideal testbed because the lapse is an explicit harmonic function, so this
question becomes a tractable (but nontrivial) problem in bifurcation theory
and validated numerics rather than a purely numerical experiment.

**Abstract (short).** For the equilateral three-center MP family
`(M1,M2,M3)=(1,1,λ)`, the finite lapse critical structure undergoes two exact
bifurcations — a symmetry-breaking pitchfork at `λ₋ ≈ 0.6739` and a fold at
`λ₊ ≈ 1.1363` — following the pattern `2S₁ → 3S₁+S₂ → 2S₁`. These results are
backed by analytic normal-form reduction together with interval/Krawczyk
root certification, Brouwer-index consistency, and independent validated
numerics (outward-rounded interval arithmetic and arbitrary-precision ball
arithmetic) — this repository is that independent numerical certification.
For the asymmetric family `(1+ε,1-ε,λ)`, the pitchfork unfolds into a cusp
with a validated `|ε|^(2/3)` scaling law. The paper also compares this
gradient-skeleton descriptor against contour/Reeb-type representations of
the same scalar field.

## What isn't certified

Everything above is PASS except one deliberately scoped-down piece: the
phase-diagram degeneracy exclusion only covers the **on-axis** mechanism
(the fold/pitchfork curves already characterized above) on the **middle**
parameter slab between the two bifurcations. It does not cover possible
off-axis degeneracies, nor the two unbounded tail slabs below the pitchfork
point or above the fold point. See "Phase-diagram tails" below for the
(non-certified) reasoning sketch for why those are expected to be safe, and
why finishing them rigorously was out of scope for this pass.

## Mathematical setup

Units `G=c=1`. Metric

```
ds^2 = -U^-2 dt^2 + U^2 dx^2,   U = 1 + Σ_a M_a / |x - x_a|
```

Lapse `N = U^-1`, so `∇N = -U^-2 ∇U` and finite lapse critical points are
exactly the critical points of `U`.

Source positions: equilateral triangle, circumradius 1, in the z=0 plane:

```
P1 = ( 1,        0,        0)
P2 = (-1/2,  √3/2,        0)
P3 = (-1/2, -√3/2,        0)
```

Since all sources lie in z=0,

```
∂_z U = -z Σ_a M_a / r_a^3
```

so every finite critical point has z=0. All root certification below is
therefore done in the (x,y) plane (or in symmetry-adapted (r,t) / (r,s)
coordinates), which is an *exact* analytic reduction, not an approximation.

**Coordinate convention.** The code places `λ` at `P1=(1,0,0)` and the two
equal (or near-equal, in the asymmetric family) masses at `P2,P3` — an
equally valid labeling puts `λ` at `P3` instead. The two are related
by a rigid +120° rotation of the plane (verified numerically to float
precision: `U_alt(x,y) == U_code(rotate120(x,y))` for both the symmetric
and asymmetric families), so every quantity computed here — bifurcation
values, root counts, Morse indices, the Brouwer degree, the cusp-scaling
ratio — is identical to what that alternate labeling would produce; only
the raw (x,y) coordinates of individual roots are rotated.

## Symmetric-axis reduction and the exact s=t² identity

With `P1=(1,0,0)` as the reference source, coordinates `(r,t)` measure
along/perpendicular to the P2–P3-bisecting axis (see `src/mp_model.jl` for
the exact map to Cartesian (x,y)). Distances squared:

```
R1^2 = r^2 + r + t^2 - √3 t + 1
R2^2 = r^2 + r + t^2 + √3 t + 1
R3^2 = (1-r)^2 + t^2
```

`U(r,-t;λ) = U(r,t;λ)` exactly (reflection symmetry across t=0).

To avoid the removable-singularity interval blowup of `1/√(R1^2)+1/√(R2^2)`
at t=0, we use `s=t^2` and the **exact algebraic identity**

```
a = r^2 + r + 1 + s
D = a^2 - 3s
1/√(a-√(3s)) + 1/√(a+√(3s)) = √( 2a/D + 2/√D )
```

(proved by rationalizing: `(a-√(3s))(a+√(3s)) = a^2-3s = D`, and
`(a-√(3s))+(a+√(3s)) = 2a`, so the sum of reciprocal square roots squares to
`1/(a-√(3s)) + 1/(a+√(3s)) + 2/√D = 2a/D + 2/√D`). This holds for all
`s≥0` with `D>0`, including s=0 exactly, with no cancellation error, because
the right-hand side never subtracts two nearly-equal square roots. Hence

```
V(r,s,λ) = 1 + √(2a/D + 2/√D) + λ/√((1-r)^2+s)
```

is *identically* equal to `U(r,t,λ)` under `s=t^2`, not an approximation of
it, and is the object all interval code evaluates.

`Q := U_t/t = 2 V_s` on t≠0 (removable at t=0 by the same identity, evaluated
via V_s directly — no division by t ever occurs in the interval code).

## Search-domain justification: convex hull and exclusion disks

The completeness search (λ=0.5/0.8/1.2) needs a bounded region to
subdivide, and needs to avoid the singular source points. Both are
justified analytically here, not by interval computation, per the
requirement that this kind of reasoning live outside the code.

**Convex hull.** For `U(x)=1+Σ M_a/|x-x_a|` with all `M_a>0`, every critical
point of `U` lies in the convex hull of `{x_a}`.

*Proof.* Suppose `x` is outside the (compact, convex) hull. By the
hyperplane separation theorem there is a unit vector `n` and a gap `δ>0`
with `n·(x-x_a) ≥ δ > 0` for every source `a`. Then

    ∇U(x)·n = -Σ_a M_a (x-x_a)·n / |x-x_a|^3 ≤ -δ·Σ_a M_a/|x-x_a|^3 < 0,

so `∇U(x)≠0`. Hence every critical point lies in the hull. ∎

This justifies restricting the box-subdivision search domain to a padded
bounding box of the hull.

**Exclusion disks around each source.** Fix radius ρ=0.25. Near source `a`,
split `∇U`'s radial-away-from-`a` component into the source's own term
(magnitude `M_a/r²` at distance `r` from `x_a`) and the other two sources'
contribution (bounded, since `x` stays at least `d_ab-ρ` from source `b`,
where `d_ab=√3` is the common pairwise distance for this equilateral,
circumradius-1 triangle). For masses in the ranges used in this project
(`M_a ≤ 1.2`), the worst case is excluding around a unit-mass source when
the third mass is `λ=1.2`:

    M_a/ρ² = 1/0.25² = 16          (own pull, lower bound)
    Σ_{b≠a} M_b/(d_ab-ρ)² = 2.2/(1.732-0.25)² ≈ 1.00   (external pull, upper bound)

`16 > 1.00` with a >15x safety margin, so the own-source term strictly
dominates and `∇U≠0` throughout each exclusion disk. Checked similarly for
every source/λ combination actually used (the λ=0.5/0.8/1.2 completeness
runs and the asymmetric family's small-ε runs) — always ≥8x margin. Boxes
fully contained in an exclusion disk are skipped by the search (`exclude`
predicate in `isolate_roots`, `src/krawczyk.jl`) without ever evaluating
`U`'s gradient there, which would be numerically singular at the source.

The same ρ=0.25 bound is reused directly in the phase-slab search
(`proof/phase_slabs.jl`) to justify stopping its on-axis search at distance
0.03 from the λ-source — well inside the proven exclusion disk — since
that script's λ range is a subset of the range this bound was checked
against.

## Morse index convention (S0/S1/S2 labels)

At any finite critical point (on z=0, since `∂_zU=-zΣM_a/r_a³` vanishes
there identically), U's 3D Hessian is block-diagonal: the (x,y) block plus
a pure `U_zz` entry, because `U_xz=U_yz=0` at z=0 (odd in z). Direct
computation:

    ∂U/∂z = -zΣM_a/r_a³
    ∂²U/∂z² = -ΣM_a/r_a³ - z·∂/∂z[ΣM_a/r_a³]  =(at z=0)=  -ΣM_a/r_a³  <  0

**`U_zz<0` always** — moving off the source plane strictly decreases U,
since every source is IN that plane, so z=0 is a local *maximum* of U along
z. (This sign is easy to get backwards; a wrong guess here was caught by a
completeness run producing a Morse label that didn't match the expected
multiset, and traced back to this derivation.)

U's full 3D Morse index is therefore `1 + (negative-eigenvalue count of the
(x,y) block)` — the always-negative z-eigenvalue contributes the fixed `1`.
At a critical point, N=1/U's Hessian equals `-Hessian(U)/U²` exactly (the
first-derivative cross term vanishes there), a uniformly negative scalar
multiple, so it flips the sign of every eigenvalue: N's index = 3 - U's
index. Combining:

| (x,y) block | U's 3D index | N's index (label) |
|---|---|---|
| det>0, trace<0 (in-plane max) | 3 | 0 → S0 |
| det<0 (in-plane saddle) | 2 | 1 → **S1** |
| det>0, trace>0 (in-plane min) | 1 | 2 → **S2** |

S0 is not expected for any λ used in this project (and the code flags it
loudly, never silently, if it ever occurs).

## Boundary degree includes the sources' own index

`proof/degree_check.jl` cross-checks the Brouwer degree (computed
elsewhere as the sum of `sgn(det H_U)` over interior roots, always -2) via
a different method: walking the boundary of a large rectangle and counting
how many times `∇U` winds around the origin. The *raw* winding number of
that rectangle is **+1**, not -2 — this is correct, not a bug: the
rectangle necessarily also encloses the 3 point-source singularities of
`∇U`, and each is an isolated simple pole contributing its own local
index. For `U=1+M/r` near one source, `∇U=-M·r̂/r²`; walking a small CCW
loop around it, `-r̂`'s angle increases by 2π over the loop too — local
index +1, for any `M>0`. Three sources contribute +3, so
`(boundary degree) = (sum of finite critical point indices) + 3`, i.e.
`1 = -2 + 3`. The script reports the corrected value (`boundary degree -
3`) and requires it to equal -2, matching the index-sum result from an
independent computation.

## Phase-diagram tails (not certified)

`proof/phase_slabs.jl` interval-certifies the on-axis degeneracy exclusion
for the middle slab between the two bifurcation points (zero additional
roots of either the fold-curve or pitchfork-curve system). It does not
interval-certify the two tail slabs below the pitchfork point or above the
fold point. Rigorously extending the search there (via a `λ→0+` /
`μ=1/λ→0+` rescaling of the degeneracy system, re-deriving exclusion-disk
bounds in the rescaled variables) is a comparable amount of work to
everything above combined, and was not carried out.

The (non-certified) expectation for why no new degeneracy appears there:
as `λ→0+`, the on-axis stationarity condition reduces to
`-(2r+1)/(r²+r+1)^{3/2}=0`, which has no root inside the admissible range
(the numerator vanishes only at the domain's excluded edge); as `λ→∞`, `U`
is dominated by the single λ-source term, which is monotonic and
contributes no interior critical point of its own, pushing any admissible
on-axis critical point toward the same excluded edge from the other
direction. This is a plausibility sketch, not a certified result.

## Reproducibility and honesty conventions

- No certificate is marked PASS from a point-float evaluation.
- No certificate is marked PASS from a dense grid scan alone.
- Any interval containing 0 where a strict sign is required is reported
  UNRESOLVED, never rounded to a guessed sign.
- Reference numbers quoted in the original problem statement (e.g.
  `V_rr ≈ [2.507865, 2.966038]`) are targets to reproduce independently,
  never hardcoded into the certificate logic.
